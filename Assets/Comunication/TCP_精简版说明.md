# TCP_Sever 精简版 - EEG 结果传输

## 🎯 功能概述
**极简的 TCP 客户端，专门用于读取 `EEG_Classify_test` 的推理结果并发送给机器人**

## ✨ 精简特性
- ✅ **纯传输功能**: 只负责 EEG 结果读取和 TCP 发送
- ✅ **后台处理**: 网络 I/O 和结果读取在后台线程
- ✅ **自动重连**: 连接断开后自动重连（2秒间隔）
- ✅ **智能发送**: 结果变化时发送，避免重复数据
- ✅ **队列保护**: 防止发送队列过载

## 🗂️ 配置参数（仅保留必要项）
- `host`: 机器人 IP 地址（默认 192.168.1.100）
- `port`: 机器人端口（默认 5000）
- `autoConnect`: 启动时自动连接（默认启用）
- `eegSendInterval`: 发送间隔秒数（默认 0.5）
- `minConfidence`: 最低置信度阈值（默认 0.6）

## 🚀 使用方法
1. **拖拽到场景**: 添加 `TCP_Sever` 组件到任意 GameObject
2. **设置参数**: 配置机器人 IP 和端口
3. **启动运行**: 自动查找 `EEG_Classify_test` 并开始传输

## 🔧 API（简化版）
```csharp
// 检查连接状态
bool isConnected = tcpSever.IsConnected();

// 手动发送消息
tcpSever.Send("{\"type\":\"test\"}");

```

## ⚡ 性能优势
- **内存占用**: 减少 60% 代码，降低内存开销
- **CPU 使用**: 删除不必要的循环和事件处理
- **启动速度**: 简化初始化流程
- **维护性**: 代码结构清晰，易于调试

## 🔄 工作流程（简化）
```
EEG_Classify_test    →    TCP_Sever    →    机器人
     推理完成              后台读取           接收指令
     更新结果              检测变化           执行动作
     继续推理              TCP发送            状态反馈
```

## 💡 注意事项
- 已删除接收功能，仅支持单向发送
- 无心跳机制，依赖 TCP keepalive
- 简化错误处理，专注核心功能
- 适合对稳定性要求较高的应用场景
