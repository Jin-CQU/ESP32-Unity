## 🔧 核心函数注释详解

### 🚀 Unity 生命周期函数

#### `Start()`
- **功能**: 初始化 TCP 客户端和 EEG 数据读取
- **流程**: 查找 EEG 组件 → 缓存反射字段 → 启动后台处理 → 自动连接
- **关键点**: 确保所有依赖组件就绪后再启动网络连接

#### `Update()`
- **功能**: 主线程处理 EEG 结果队列
- **特点**: 限制每帧最多处理 3 个结果，避免主线程阻塞
- **效率**: 从后台线程队列中取出预处理的结果

#### `OnDisable()`
- **功能**: 清理资源和停止所有任务
- **安全性**: 等待后台任务完成（最多 1 秒），防止资源泄漏
- **完整性**: 断开连接并清理所有相关资源

### 🌐 网络连接函数

#### `StartConnectLoopAsync()`
- **功能**: 异步连接循环，主要的网络连接管理
- **特点**: 持续重连机制（2秒间隔）
- **线程安全**: 使用 CancellationToken 支持优雅的任务取消
- **错误处理**: 连接失败时自动重试

#### `SendLoopAsync(CancellationToken token)`
- **功能**: 后台发送循环，处理发送队列中的消息
- **协议**: 4 字节 little-endian 长度前缀 + UTF-8 负载
- **性能**: 异步 I/O 操作，不阻塞其他线程
- **可靠性**: 发送失败时自动退出，触发重连

#### `SafeCloseClient()`
- **功能**: 安全关闭 TCP 客户端连接
- **健壮性**: 使用 try-catch 确保资源清理完整
- **防护**: 即使某个步骤失败也能继续清理其他资源

### 🧠 EEG 数据处理函数

#### `CacheEEGReflectionFields()`
- **功能**: 缓存 EEG 分类组件的反射字段信息
- **性能优化**: 避免每次读取时重复反射查找
- **访问权限**: 使用 NonPublic | Instance 标志访问私有字段
- **错误处理**: 反射失败时记录警告但不中断程序

#### `StartEEGBackgroundProcessing()`
- **功能**: 启动 EEG 后台处理任务
- **线程模型**: 后台线程定期读取，避免阻塞主线程
- **单例性**: 只能启动一次，重复调用被忽略
- **依赖检查**: 确保 CancellationTokenSource 初始化

#### `EEGBackgroundReadingLoop(CancellationToken token)`
- **功能**: EEG 后台读取循环
- **时间控制**: 使用 realtimeSinceStartup 不受 timeScale 影响
- **条件检查**: 只有 TCP 连接正常时才读取
- **队列机制**: 读取结果放入线程安全队列

#### `ReadEEGResultsSafely()`
- **功能**: 安全读取 EEG 推理结果
- **智能过滤**: 应用置信度阈值和变化检测
- **重复检测**: 避免发送相同的数据，提高传输效率
- **异常安全**: 反射操作失败时返回 null 而不是崩溃

#### `ProcessEEGResultQueue()`
- **功能**: 处理 EEG 结果队列（主线程）
- **JSON 构造**: 将 EEG 结果转换为标准 JSON 格式
- **帧率保护**: 每帧最多处理 3 个结果
- **数据标准化**: 包含类型、时间戳、置信度等完整信息

### 📤 公共 API 函数

#### `Send(string message)`
- **功能**: 将消息入队，后台线程发送
- **协议**: UTF-8 编码 + 4 字节长度前缀
- **队列保护**: 防止队列无限增长（最大 1000 条）
- **线程安全**: 使用 ConcurrentQueue 支持多线程访问

#### `Connect()`
- **功能**: 手动触发连接（autoConnect=false 时使用）
- **防重复**: 已有连接时忽略调用
- **异步启动**: 启动连接循环但不阻塞调用线程

#### `Disconnect()`
- **功能**: 立即断开并停止所有后台任务
- **完整性**: 取消所有异步任务并清理资源
- **同步操作**: 确保调用完成后连接确实断开

#### `IsConnected()`
- **功能**: 检查 TCP 连接状态
- **多重验证**: 检查客户端、连接状态和网络流
- **实时性**: 反映当前真实的连接状态

#### `SendEEGResult(int, float, int)`
- **功能**: 手动发送 EEG 分类结果
- **格式标准化**: 与自动发送使用相同的 JSON 格式
- **连接检查**: 发送前验证连接状态
- **外部接口**: 供其他组件直接调用

### 🔄 兼容性函数

#### `CheckAndSendEEGResults()`
- **功能**: 主线程模式的 EEG 结果处理（兼容性）
- **完整流程**: 包含反射查找、验证、构造、发送的完整逻辑
- **性能影响**: 在主线程中执行，可能影响帧率
- **保留原因**: 为了向后兼容和调试需要
